    Database inspection

    Metadata & read-only SQL

    No database credentials or connection are configured. Catalog capture and RLS verification remain operator-run procedures in the migration runbook.

    The future executor must enforce a read-only transaction, timeout, row and byte limits, audited queries, restricted function access and RLS. Elevated migrations are not available.

    Updates & maintenance

    Update execution is gated

    No update or restart helper is installed. Before an update, require a verified backup, isolated restore evidence, version compatibility review and a rehearsed rollback.

    Disruptive actions must require recent re-authentication, explicit confirmation and a recorded reason. This app cannot perform them.
